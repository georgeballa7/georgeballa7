### 🚕 NYC Taxi Demand Forecasting & Business Analytics

An independent end-to-end data project for analyzing and forecasting NYC
Yellow Taxi demand while connecting operational demand patterns with
commercial insights.

The project covers the full path from large-scale data processing and data
modeling to machine learning, API-based serving, interactive analytics, and
cloud deployment.

**Highlights**

- Built a multi-page Streamlit application for demand exploration,
  forecasting, business analytics, and strategic insights
- Separated compute-intensive data processing from lightweight application

### 🏭 Machine Reporting & Analytics — DSI Capstone Project

A collaborative end-to-end data application developed as the capstone project
of my Data Analytics & Data Science training.

The application provides production and maintenance analytics for an industrial
machine environment. It combines machine and event data, maintenance records,
operational KPIs, ticket analysis, and text clustering within an interactive
reporting application.

The solution uses a Streamlit frontend communicating through REST APIs with a
FastAPI backend and a relational database. Analytical functionality includes
machine availability, error and downtime analysis, MTTR/MTBF, ticket analysis,
and clustering of ticket descriptions.

**My contribution**
- Developed the initial version of the Streamlit application
- Created the Streamlit UI mockup used during application development
- Contributed to exploratory data analysis in the project notebooks
- Contributed to the restructuring of the project database
- Collaborated with the team as the frontend implementation was subsequently
  refactored and integrated into the final application

**Project Stack:**  
Python · Pandas · Streamlit · FastAPI · SQLAlchemy · SQLite ·
Scikit-learn · Altair · REST APIs

💻 [Project Repository](https://github.com/hanyu1774/DSI.FE.Abschlussprojekt.DeviceReport)
